Update cloudflared

Hiện tại 2025.8.1 → mới nhất 2025.9.0 (GitHub releases). Lệnh sẽ chạy:

curl -Lo /tmp/cloudflared.deb https://github.com/cloudflare/cloudflared/releases/download/2025.9.0/cloudflared-linux-amd64.deb
dpkg -i /tmp/cloudflared.deb
systemctl restart cloudflared-*   # restart lần lượt từng tunnel

⚠ Mỗi tunnel mất kết nối vài giây khi restart. Có thể chọn "chỉ cài, restart sau".

Thiếu cert.pem cho user «root»

Server không có browser. Chọn 1 cách:

1) Trên máy có browser: cloudflared login rồi scp ~/.cloudflared/cert.pem root@IP:/root/.cloudflared/cert.pem

2) Chạy cloudflared login trong terminal SSH của server, mở URL hiện ra trên browser.

CFKit không tự chạy login (cần tương tác). Bấm "Check lại" sau khi xong.
